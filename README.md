### 💻 Neler Yapıyorum

- **Oyun geliştirme** — Unity ile 2D ve 3D oyunlar; düşman AI ve NavMesh pathfinding, state machine yapıları, ScriptableObject tabanlı veri sistemleri, animasyon ve fizik mekanikleri. Photon / Netcode ile multiplayer tarafına da giriyorum.
- **Backend** — FastAPI ile REST API ve WebSocket servisleri, JWT kimlik doğrulama, PostgreSQL & SQLite veri modelleme.
- **Otomasyon** — Selenium ve BeautifulSoup ile veri kazıma, GitHub Actions üzerinde periyodik çalışan bildirim pipeline'ları.
- **Bilgisayarlı görü** — PyTorch ve OpenCV ile nesne tespiti, model eğitimi ve görüntü işleme üzerine çalışıyorum.
- **Web** — React / Vite ile arayüz geliştirme, Firebase entegrasyonu.
